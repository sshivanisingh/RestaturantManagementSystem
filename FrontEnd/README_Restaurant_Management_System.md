# 🍴 Restaurant Management System

A fully functional **Restaurant Management Platform** built with **Next.js 15, React, Tailwind CSS, and Redux Toolkit**.  
Includes **role-based access**, modern UI, CRUD features, and responsive design.

---

## 🚀 Features

- Role-based Access: Admin, Accountant, Delivery, Cart Manager, Customer, etc.
- Fully Responsive UI (Mobile + Desktop)
- LocalStorage-based Data Persistence (No backend required)
- Modern Tech Stack (React, Next.js, Tailwind, Redux Toolkit)
- Search, Filter, CRUD operations
- Reservation, Orders, Cart, Checkout modules
- Favorites & Profile management
- Dark/Light Theme support

---

## 📦 Installation

1. Download the project ZIP file (Google Drive link after payment).
2. Extract the ZIP.
3. Open terminal in the project folder.
4. Run the following commands:

```bash
npm install
npm run dev
```

Now open `http://localhost:3000` in your browser.
